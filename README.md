# astrbot_plugin_bookkeeping

All-in-AI 智能记账插件，提供 22 个 LLM 工具与美观的 WebUI 仪表盘。

## 功能

- **自然语言记账**：在聊天中直接用自然语言描述，LLM 自动调用工具完成记账
- **交易管理**：支持支出 / 收入 / 转账，按分类、账户、标签、日期、关键字筛选
- **多账户**：支持现金、银行卡、支付宝、微信、信用卡等多种账户类型
- **分类与标签**：自定义分类（emoji 图标 + 颜色）和标签体系
- **统计分析**：每日趋势、分类占比、收支对比、Top 支出等图表
- **WebUI 仪表盘**：iOS 风格液体玻璃 UI，支持深色模式与自定义二次元背景
- **数据导出**：JSON 全量导出 / CSV 交易导出

## 安装

将本插件放入 AstrBot 的 `plugins` 目录，重启后自动安装依赖：

```
plugins/astrbot_plugin_bookkeeping/
```

依赖：`aiosqlite >= 0.19.0`

## 配置

在 AstrBot 管理后台 → 插件配置中编辑：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `currency` | 货币符号 | `¥` |
| `timezone` | 时区 | `Asia/Shanghai` |
| `warn_large_amount` | 大额预警阈值（0 不预警） | `1000` |
| `page_size` | WebUI 每页条数 | `20` |
| `enable_image_receipt` | 图片账单 | `true` |
| `anime_bg_api` | 背景图 API 列表 | 内置默认源 |

## 使用示例

在聊天窗口直接对 AstrBot 说：

- "记一笔 餐饮 50 午餐"
- "工资到账 8000"
- "本月账单" / "钱花在哪了"
- "从银行卡转 500 到支付宝"
- "我还有多少钱"
- "新建账户 基金 余额 1000"

## WebUI

在 AstrBot 仪表盘中打开本插件页面，可进行可视化管理：仪表盘、交易管理、分类管理、账户管理、标签管理、设置。
